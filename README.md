It is necessary to create a form for registering internet package sales. The internet package consists of the following parameters:
	Speed: 2, 5, 10, 20, 50, or 100 Mbps.
	Data Allowance: 1, 5, 10, or 100 GB, or Flat.
	Contract Duration: One or two years.
	User’s Name and Surname: To be entered.
	User’s Address: To be entered.

The application should allow for the following functionalities:

Record keeping of contract creation and sold packages, including:
	Viewing all sales.
	Adding new sales.
	Deleting existing sales.

The application can be implemented within a single window or in separate windows.

Using the MVC pattern and FXML is recommended, but not mandatory. For the domain model, it is required to create a class representing the internet package.

The application should be styled using CSS.
